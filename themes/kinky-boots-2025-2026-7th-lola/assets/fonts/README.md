# Local print fonts

Current font binaries are served locally, matching the existing local-font/CSP policy. Notices and source links for previously tested fonts are retained below even when their unused binaries have been removed.

- `RobotoSlab.ttf`: [Google Fonts / Roboto Slab](https://github.com/google/fonts/tree/main/apache/robotoslab), with `RobotoSlab-LICENSE.txt`.
- `Oswald.ttf`: [Google Fonts / Oswald](https://github.com/google/fonts/tree/main/ofl/oswald), with `Oswald-OFL.txt`.
- `NotoSansKR.ttf`: [Google Fonts / Noto Sans KR](https://github.com/google/fonts/tree/main/ofl/notosanskr), with `NotoSansKR-OFL.txt`.
- Formerly tested `NanumPenScript-designer.ttf` (binary removed): [Google Fonts / Nanum Pen Script](https://github.com/google/fonts/tree/main/ofl/nanumpenscript), a four-character subset for `디자이너`, with retained `NanumPenScript-OFL.txt`.
- Formerly tested `KCCEunyoung.woff` (binary removed): KCC은영체, 한국저작권위원회. [Official source](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200018&wrtSn=13072022); [official OFL listing](https://gongu.copyright.or.kr/gongu/bbs/B0000001/view.do?menuNo=200037&nttId=4161&pageIndex=6&searchCnd=1&searchWrd=). Retained notice: `KCCEunyoung-LICENSE.txt`.
- `KCCImkwontaek.woff2`: KCC임권택체, 한국저작권위원회. Applied only to `디자이너`; CCL 저작자표시. [Official source](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200023&wrtSn=13285735).

IBM Plex Mono reuses the existing local `themes/elisabeth-2026-6th-lucheni/fonts/plexmono-600.woff2` file without modifying it.
