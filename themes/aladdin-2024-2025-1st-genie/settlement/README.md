# 정산판·PNG 연결

공통 정산·기록 동작은 루트 `settlement-app.js`와 `data.js`, 좌석선은 `seat-lines.js`를 재사용합니다.

알라딘 전용 `view.js`가 서울·부산 스위치와 중립적인 임시 PNG를 담당합니다. 기본은 샤롯데(OP열 제외)이며 선택한 극장의 좌석도만 표시하고, 다른 지역은 관람 횟수만 표시합니다. 기록 원본을 변경하지 않고 표시할 때만 부산 좌석 ID를 지도 형식으로 해석합니다.

공통 엔진의 테마 훅을 통해 화면·팔레트·확대·PNG 저장 확인 창을 재사용합니다. 실제 디자인이 정해지면 `view.js`, `theme.css`의 배치·장식만 바꿉니다. 기존 두 작품의 PNG 레이아웃은 재사용하지 않습니다. `theme-registry.js`의 export 파일 경로가 빈 이유는 별도 iframe 대신 테마의 `exportPng` 훅으로 현재 극장을 내보내기 때문입니다.

`WORK.preparing` 상태라 로그인·원격 저장·실제 회차 편집은 비활성입니다. 공식 회차 자료는 아직 없습니다. 자동 검증의 가상 회차·관람 기록은 테스트에만 존재합니다.
