# 알라딘 초연 좌석 자료

- 서울: 사용자 확인에 따라 기존 킹키부츠 샤롯데씨어터 좌석 데이터를 재사용합니다. 알라딘은 OP석을 운영하지 않으므로 OP열만 제외했습니다.
- 부산: [드림씨어터 공식 좌석배치도](https://www.dreamtheatre.co.kr/DREAM/DREAMTHEATRE/SEATINGMAP)를 2026-10-22 확인하고 층·열·번호 및 휠체어석을 전사했습니다.
- 원본: [1층](https://www.dreamtheatre.co.kr/Contents/Images/Sub/img_seating_1F.png), [2층](https://www.dreamtheatre.co.kr/Contents/Images/Sub/img_seating_2F.png), [3층](https://www.dreamtheatre.co.kr/Contents/Images/Sub/img_seating_3F.png). `dream-official-1f.png`부터 `dream-official-3f.png`까지 원본을 보존합니다.

공식 그림의 모든 번호를 보존합니다. 극장 안내문의 총 좌석 수와 그림에서 센 좌석 수가 일치하지 않는 경우, 숫자를 임의로 삭제하거나 추가하지 않고 그림을 따릅니다. 판매등급 및 공연별 판매 여부는 별도 자료가 필요합니다.

그림에서 전사한 부산 좌석은 1층 1,028석(휠체어 12석 포함), 2층 398석(휠체어 6석 포함), 3층 280석입니다. 안내문의 1,046석·402석·279석과 차이가 있습니다. 1층 25열 중앙 음향 부스는 비우고, 2층 7열의 일반석과 휠체어석을 함께 보존했습니다.

웹 좌석도는 공용 엔진의 동일 크기 좌석과 직각 SVG 선을 사용합니다. 곡선·엇갈린 물리적 의자 배치·휠체어석의 실제 폭을 재현하는 실측 도면이 아닙니다. 통로·중앙 부스의 빈 공간과 좌석 식별자는 데이터로 유지합니다.
