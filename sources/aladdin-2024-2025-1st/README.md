# 알라딘 초연 자료

강홍석 지니의 서울·부산 초연을 포함합니다. 서울은 샤롯데씨어터(OP열 제외), 부산은 드림씨어터입니다. 극장과 OP열 제외는 사용자 확인 사항입니다. 공식 일정·캐스팅표·좌석도·배우 사진 원본과 출처를 이곳에 보존합니다. 실제 공연 기간·전체 캐스팅과 회차는 자료 확인 후 추가합니다. 임의 회차나 타 작품 사진을 넣지 않습니다.

`productions/aladdin-2024-2025-1st/data/`는 검증된 웹용 데이터, `themes/aladdin-2024-2025-1st-genie/`는 화면과 배포 자산입니다. 작품 ID `aladdin-2024-2025-1st`는 기록 저장에도 사용되므로 추후 디자인·자료가 추가돼도 유지합니다.
